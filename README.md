# 灵元子 (Lingyuanzi)

**一种基于「先验方向 + 内容表」互补注意力的持久记忆语言模型**

> A brain-inspired byte-level language model with persistent memory — replacing KV cache with a fixed-length "direction state".

---

## 一句话

用「持久方向状态 **g** + 内容表 **contents**」替代 Transformer 的 KV 缓存，实现**跨序列（cross-batch）的持久记忆**；这套机制天然是「先验 + 预测误差 + 纠偏」的**预测编码（predictive coding）**——一个**状态级的世界模型**，而不是像素级的生成模型。

---

## 核心思想

```
g（先验方向）      ← 持久状态，跨 batch 携带记忆，不随序列长度增长
contents（内容表）  ← 可学习的内容字典（「世界的事实」）
Rh = R @ h（偏转）  ← 「选择头」
query = g ⊙ Rh      ← 「互补」：先验 ⊙ 观测
content = read(query) ← 查内容表
```

**核心一句**：`query = g ⊙ (R @ h)` —— 先验（g）与观测（h 经 attention 的偏转）在 query 里互补，再一起去查内容表、做纠偏。

**纠偏（解决近因偏置）**：content 查出来后，通过余弦相似度去「attend」h 里跟它相关的 token，**定位**句中的关键 token，而不是只盯最后一个 token。

**g 连续累积（连乘猜想）**：`g_j = normalize(g_init ⊙ ∏(1+normalize(query_k)))` —— 串行 normalize 只压幅值不改方向，所以等价于「累乘 + 最后 normalize」，能用并行 scan 算（O(S·D) 线性）。

**read 逐元素门控（方向/位移分离）**：`content = query ⊙ contents` —— query 既是「查询」也是「门控」，不求和；g 归一化（方向）、content 不归一化（位移），两者分离。

## 关键结果（2026-10-29）

| 实验 | 结果 |
|---|---|
| g 跨 batch 记忆（正确 g vs 错误 g 的 P(答案) 比值，短事实） | **4.0x~10.4x** |
| 近因偏置修正（答案在句中） | 1.0x → **4.7x** |

## 定位：状态级世界模型

```
预测（g 先验）→ 观测（h）→ 预测误差（expl_err）→ 纠偏（更新 g）
```

完整的**预测编码回路**，与 2026 年世界模型前沿（PhiZero 的「物理语言」、V-JEPA 2 的「潜空间预测」、自由能原理）同一方向。

**差异化**：

| | Transformer | 灵元子 |
|---|---|---|
| 长上下文记忆 | KV 缓存（O(S)） | g（定长，跨 batch 携带） |
| 表示 | 符号/像素级 | 连续状态级（因果可解释） |
| 可解释性 | — | 因果干预（换 g → 观测概率变化） |
